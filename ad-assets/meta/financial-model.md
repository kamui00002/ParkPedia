## 3. Meta 機械学習の閾値ギャップ

Meta の入札最適化が機能するためには、広告セットあたり**週 50 install** (Apple-recommended SKAN learning phase exit) が必要。

| 指標 | 必要値 | 本キャンペーン中央値 | ギャップ |
|------|-------|----------------|---------|
| 週 install/広告セット | 50 | 5 (=20/月÷4週) | **-90%** |
| CPI 安定収束日数 | 14日 | 30日でも未達 | 学習未完了 |

**意味**: Meta の機械学習は完走しない。CPI は安定しない可能性が高い。これは織り込み済み。「Meta が学習できない領域で何が起きるか」自体が学習成果。

## 4. ATT 拒否率の影響 (シグナル品質)

ATT 許諾シナリオ別:
- **許諾 (20-30%)**: IDFA 取得 → Meta の精密ターゲティング有効 → CPI ¥300-500 帯
- **拒否 (70-80%)**: SKAN postback のみ → 24-72h 遅延 + 粗いコホート → CPI ¥500-800 帯

加重平均 CPI = 0.25 × ¥400 + 0.75 × ¥650 = **¥588** (中央値¥500 とほぼ同水準、計算上整合)

**意味**: CPI ¥500 想定は ATT 拒否を織り込んだ後の数値。¥300 楽観シナリオは ATT 許諾率が想定以上に高い場合のみ実現。

## 5. LTV / ARPDAU ベースの ROI 計算

### 5-1. 現状 ARPDAU での LTV (悲観的だが現実)

```
LTV_180日 = ARPDAU × Day1リテンション × 平均アクティブ日数
         = ¥0.033 × 30% × 30日
         = ¥0.30/install
```

(Day1 30%、その後減衰して 6 ヶ月平均 30 日アクティブと仮定、業界標準より低め)

| 指標 | 値 |
|------|-----|
| 1インストールあたりLTV | **¥0.30** |
| 1インストールあたりCPI | **¥500** |
| LTV:CAC 比 | **0.0006** |
| Payback period | **83 年** (!) |

→ **純粋な ROI 計算では大赤字**。回収不能。

### 5-2. もしリワード広告等で ARPDAU が ¥0.5 まで改善した場合 (Obsidian の最低目標値)

```
LTV_180日 = ¥0.5 × 30% × 30日 = ¥4.5/install
```

| 指標 | 値 |
|------|-----|
| 1インストールあたりLTV | ¥4.5 |
| 1インストールあたりCPI | ¥500 |
| LTV:CAC 比 | 0.009 |
| Payback period | 約 1.5 年 |

→ それでも赤字、UA に値しない。

### 5-3. 直接 ROI が出る ARPDAU 必要値

CAC = LTV を満たす ARPDAU を逆算:
```
¥500 = ARPDAU × 30% × 30日
ARPDAU 必要値 = ¥55.5
```

→ 現状 ARPDAU ¥0.033 の **1,683 倍** が必要。現実的に不可能。

## 6. 「学習」としての価値定義

純粋 ROI は赤字確定。それでも本キャンペーンに月¥10K 投じる正当化は以下:

### 6-1. 取得できる学習データ

| データ | 価値 (次アプリ開発で何に使うか) |
|--------|-----------------------------|
| Meta SDK 本番動作の検証 | 次アプリで同じ詰まりをしない (時間節約 数十時間相当) |
| ATT 拒否率の実測 | 次アプリの IDFA 依存度設計の根拠 |
| CPI ¥300/¥500/¥800 のどこに着地するか | 次アプリの広告予算現実値 |
| Day1 / Day7 / Day30 リテンション (UA経由ユーザー) | オーガニックとの差分が分かる |
| SKAN コンバージョン値分布 | SKAN スキーマ設計のノウハウ |
| Meta クリエイティブ A/B 自然観察 (3案) | 訴求軸ごとの CTR/CPI 差を肌で知る |
| Ads Manager UI の操作経験 | 次アプリのキャンペーン立ち上げが半分の時間で済む |

### 6-2. 機会コスト評価

- 月¥10K = 学習教材費・書籍 5 冊分相当
- もし同じ¥10K で書籍読むなら情報密度は高いが「自分で動かして得る学び」は得られない
- → 体験学習として妥当な投資額。ROI を求めない領域。

### 6-3. 損切りライン (財務的)

| トリガー | 累計支出時 | アクション |
|---------|---------|---------|
| 7日CPI > ¥1,200 (¥2,331消化) | ¥2,331 | 即停止 → クリエイティブ再制作 or 撤退 |
| 14日 install < 8 件 (¥4,662消化) | ¥4,662 | 残予算消化後撤退、第二弾は半年後 |
| 30日完走 (¥10,000消化) | ¥10,000 | 学習データ整理 → 次アプリへ |

## 8. 結論

- **純粋 ROI 計算は赤字**: 現 ARPDAU では 1 インストール ¥500 投じて ¥0.30 しか回収できない (1,667倍の赤字)
- **本キャンペーンの正当化は「学習投資」**: SDK 検証 + ATT 実測 + Meta UI 体験 + クリエイティブ反応観察に¥10K を支払う
- **継続判断**: 30日完走後、ARPDAU が改善しない限り月次 UA は継続しない。第二弾は次アプリ or リワード広告導入後
- **撤退基準を機械的に運用**: 感情で「もう少し回せば」とならないように、7日¥2,331・14日¥4,662 でゲートをかける

## 9. AdMob 側の並行アクション (推奨)

UA を回す前提として AdMob 側の収益化も強化すべき。Obsidian ノートでは以下が提案されている:
- **ParkPedia 公園リスト画面にネイティブ広告を追加** (バナー eCPM ¥231 → ネイティブ eCPM ¥600-1,200 期待、3-5倍)
- これにより ARPDAU が ¥0.033 → ¥0.15 程度まで改善する可能性 (まだ ¥0.5 には届かない)
- このキャンペーンと並行/前段で実施すれば、UA の ROI が多少マシになる

**ただし本プランのスコープ外**。Meta UA の学習を優先し、AdMob ネイティブ広告は別タスクで実施。
