### 2.3 テキスト面積 (Meta 20% ルール)

Meta は画像内テキスト面積が 20% を超えると配信制限する。

| アセット | 推定テキスト面積 | 判定 |
|---------|--------------|------|
| A-1 | 約 14% (左上 3 行、フォント小〜中) | ✅ 適合 |
| B-1L | 約 18% (上部 2 行、フォント中) | ✅ 適合 (上限近い、後で計測ツールで再確認推奨) |
| C-1S | 約 15% (中央 2 行、フォント中) | ✅ 適合 |

**推奨アクション**: Meta Ads Manager のクリエイティブアップロード時に「Text Overlay Tool」(<https://www.facebook.com/ads/tools/text_overlay>) で実測。20% を超えた場合は B-1L のテキストフォントサイズを縮める。

### 2.4 セーフゾーン (Story format のみ)

C-1S (1080×1920 Story) は Meta が自動的に上下に UI を被せる:
- 上部: 14% (250 px) — プロフィール表示、進行バー、メニュー
- 下部: 20% (384 px) — Send/Like ボタン、CTA Sticker

| 領域 | 重要要素 | 判定 |
|------|---------|------|
| 上部 14% (0-269 px) | 空 (緑の背景のみ) | ✅ 適合 |
| 中央 (270-1535 px) | 手の写真 + テキスト | ✅ 重要要素はここに集約 |
| 下部 20% (1536-1920 px) | 緑の背景のみ (Park Green badge は 1500 px 付近で セーフゾーン内) | ✅ 適合 |

**注**: Park Green の小さな leaf badge は下部の境界線 (1535 px) より少し上に配置されており、セーフゾーン外で表示される可能性が高い。Meta Stories の Story 広告編集画面で実機プレビュー確認推奨。

### 2.6 Meta 広告ポリシー適合性

| 観点 | チェック | 判定 |
|------|---------|------|
| 誇大広告/絶対表現 | 「もう要りません」「なくしたい」は希望表現、誇大ではない | ✅ |
| 誤解を招く UI 模倣 | C-1S v1 は Instagram UI 風要素ありで NG → v2 で完全削除済み | ✅ (v2 のみ採用) |
| 競合言及 | B-1L「Googleマップにない」は競合言及 | ⚠️ 注意 (要 review) |
| 個人を特定するイメージ | 顔判別なし、ナンバープレートなし | ✅ |

⚠️ **B-1L の競合言及リスク評価**:
- 「Googleマップにない」は Google を否定的に直接攻撃しているわけではなく、「ParkPedia には別の情報がある」という positioning。
- Meta ポリシーの「Brands and Logos」では他社ブランドの logo を勝手に使うことを禁止しているが、サービス名の比較言及は許容範囲。
- ただし審査リスクはゼロではないため、配信開始後に Meta が rejected にする場合は「ご近所の知らない公園が見つかる」など Google 言及を外した代替コピー (campaign-brief.md A-H2 等) に差し替える。

## 4. Ads Manager アップロード時のチェックポイント

User が Ads Manager に画像をアップロードする際、以下を確認:

1. **Text Overlay Tool で実測**: <https://www.facebook.com/ads/tools/text_overlay>
   - 各画像をアップロード、結果が「OK」「Low」「Medium」「High」のいずれかを表示
   - 「OK」「Low」のみ採用、「Medium」以上が出たらテキストサイズ縮小

2. **広告セット内プレビュー**:
   - Facebook フィード / Instagram フィード / Instagram Stories / Audience Network / Messenger Stories の各プレースメントでプレビュー
   - 特にストーリープレースメントで上下 UI に重要要素が隠れていないか確認
   - A-1 はフィード正方形向けに最適化、フィード以外では端がトリミングされる場合あり

3. **ポリシーチェック失敗時の対応**:
   - 「広告ポリシーに違反」と表示された場合、原因コードを Meta が表示する
   - 多くの場合は「Text in image too high」(20% 超過) なので、テキストサイズを縮小して再アップロード
